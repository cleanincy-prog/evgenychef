# Задача: заменить шрифтовую систему сайта evgenychef.com

Сайт — персональный сайт частного шефа (Кипр), язык интерфейса русский, сборка Next.js
со статическим экспортом. Нужно заменить типографику. Разметку, цвета, копирайтинг,
анимации и структуру секций НЕ трогать.

## Что сейчас (проверено на продакшене)

В CSS объявлены три переменные, и все три ведут на одну гарнитуру:

    --font-pencil: "Bellota Text", "Trebuchet MS", sans-serif;
    --font-sans:   var(--font-pencil);
    --font-display: var(--font-pencil);

Bellota Text вшита в CSS двумя @font-face как base64 data-URI, оба — вес 400,
font-display: block, с unicode-range: кириллица `U+301,U+400-45F,U+490-491,U+4B0-4B1,U+2116`
и латиница `U+??,U+131,U+152-153,...`.

Начертаний 500/600 и курсива в сборке нет вообще. var(--font-display) используется
только в правиле `h1,h2,h3`. Палитра (не менять): --paper #f4efe5, --ink #0a0a0a,
--muted #6e665a, --gold #a0792e, --gold-text #72561f, --rule #c8c0b3.

## Целевая система — три гарнитуры по ролям

- **Spectral** — голос: логотип, h1, h2, h3, названия блюд, курсивные акценты.
- **Golos Text** — текст и интерфейс: абзацы, списки, кнопки, микрокопия, вопросы FAQ.
- **IBM Plex Mono** — только числа и служебные лейблы: номера станций 01–04, номера
  подач, цены, число гостей, часы.
- **Caveat** — опционально, только рукописные пометки на полях (1–2 строки на страницу).

Правила: антиква не набирает интерфейс, гротеск не набирает имя и заголовки,
моноширинный появляется только там, где есть цифры.

## 1. Подключение шрифтов

Отказаться от base64-инлайна: положить .woff2 в `public/fonts/`, подключить через
@font-face с `font-display: swap` (сейчас `block`), добавить `<link rel="preload">`
для двух файлов первого экрана — Spectral 400 (кириллица) и Golos Text 400 (кириллица).

Нужные начертания:
- Spectral: 400, 500, 400 italic (статические, вариативной версии нет)
- Golos Text: 400, 500, 600 — предпочтительно одним вариативным файлом
  (`font-weight: 400 900` в @font-face), иначе тремя статическими
- IBM Plex Mono: 400
- Caveat: 400 (только если оставляем рукописные пометки)

Каждый шрифт субсеттить в два файла — кириллица и базовая латиница — и объявить
через unicode-range, повторив ту же схему, что уже используется для Bellota.
Команда (fonttools):

    pyftsubset Spectral-Regular.ttf \
      --unicodes="U+0301,U+0400-045F,U+0490-0491,U+04B0-04B1,U+2116" \
      --layout-features="kern,liga,tnum,locl" \
      --flavor=woff2 --output-file=public/fonts/spectral-400-cyrillic.woff2

Для латинского подмножества: `--unicodes="U+0000-00FF,U+0131,U+0152-0153,U+02BB-02BC,
U+02C6,U+02DA,U+02DC,U+2000-206F,U+20AC,U+2122,U+2191,U+2193,U+2212,U+2215,U+FEFF,U+FFFD"`.

Caveat субсеттить не целиком, а по реально используемым знакам — её файл самый тяжёлый
(~38 КБ на подмножество против ~9 КБ у Spectral).

Bellota Text и её base64-блоки удалить полностью.

## 2. Переменные

    :root{
      --font-display: 'Spectral', Georgia, 'Times New Roman', serif;
      --font-sans:    'Golos Text', -apple-system, 'Segoe UI', Roboto, sans-serif;
      --font-mono:    'IBM Plex Mono', 'SF Mono', Menlo, monospace;
      --font-pencil:  'Caveat', 'Segoe Script', cursive;
    }

--font-sans и --font-display больше не ссылаются на --font-pencil.

## 3. Токены ролей

Кегль, интерлиньяж и трекинг задаются вместе. Значения desktop → 375px:

| роль      | гарнитура          | кегль       | интерлиньяж | трекинг  |
|-----------|--------------------|-------------|-------------|----------|
| display   | Spectral 400       | 46 → 29     | 1.10 → 1.14 | −0.015em |
| title h2  | Spectral 400       | 33 → 24     | 1.18        | −0.005em |
| h3 / блюдо| Spectral 500       | 21 → 19     | 1.30        | 0        |
| copy      | Golos Text 400     | 16.5        | 1.62 → 1.70 | 0        |
| question  | Golos Text 600     | 18 → 17     | 1.35        | 0        |
| label     | Golos Text 500     | 13 → 12.5   | 1.35        | +0.02em  |
| spec/цифры| IBM Plex Mono 400  | 13          | 1.50        | +0.02em  |
| pencil    | Caveat 400         | 23 → 21     | 1.25        | 0        |

Важно: сейчас body 18px/1.45 на Bellota. Ставим 16.5px/1.62 — у Golos Text крупнее
очко, текст не станет мельче на вид, а строка получит нормальное дыхание.

Всем элементам с цифрами (цены, номера, количества) добавить
`font-variant-numeric: tabular-nums lining-nums`.

`.station-number` сейчас 27px. Перевести на --font-mono. Два допустимых варианта —
выбрать один и применить последовательно: 15px/+0.06em, если номер работает как
маркер рядом с заголовком шага, или 22px/+0.04em, если хотим сохранить крупный узел
на пунктирной линии (моноширинный при равном кегле выглядит крупнее пропорционального,
поэтому 27 → 22, а не 27 → 27).

## 4. Обязательный фикс, без него заголовок останется гротеском

Заголовки на сайте содержат внутренние `span` (в h1 — золотая строка «ваш личный»).
Правило для `span` перебивает правило для `h1`, и заголовок продолжает рендериться
гротеском. Добавить:

    h1 *, h2 *, h3 *, h4 * { font-family: inherit; }

Проверено на живой странице: без этой строки h1 остаётся в Golos Text.

## 5. Запреты

- Никакого `font-weight: 600/700` на Spectral — подключены только 400 и 500,
  браузер подделает жирность обводкой. Полужирное начертание существует в системе
  ровно в одном месте: вопросы FAQ, Golos Text 600.
- Никакого `font-style: italic` на Golos Text — курсива у неё не существует,
  браузер наклонит прямое. Все курсивные акценты — курсивом Spectral.
- Никаких прописных с разрядкой на длинных русских строках: кириллица без выносных
  элементов при трекинге 0.14em читается по буквам. Прописные допустимы только
  для латиницы, цифр и лейблов длиной до двух слов.
- Цены и любые сравниваемые числа — только моноширинным: у Golos Text цифры
  пропорциональные («1» уже «0» примерно на четверть), колонка цен не выровняется.
- Не подключать Google Fonts по сети — только самохостинг, как сейчас.

## 6. Проверка перед сдачей

1. Собрать проект, открыть страницу при 1440×900 и 375×812.
2. В DevTools убедиться, что `getComputedStyle(document.querySelector('h1')).fontFamily`
   содержит Spectral, и что то же верно для внутренних span заголовка.
3. Убедиться, что ни один элемент не рендерится синтетической жирностью или
   синтетическим курсивом (Rendered Fonts в DevTools показывает фактическое начертание).
4. Проверить, что подгружаются оба подмножества (кириллица и латиница) и что
   кириллический текст не падает на fallback.
5. Проверить, что цены и номера выровнены по вертикали в колонку.
6. Первый экран не должен мигать подменой шрифта дольше обычного swap — при
   необходимости добавить `size-adjust` в fallback-описатель.
