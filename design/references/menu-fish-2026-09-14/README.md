# Присланное блюдо

Источник — вложение пользователя Photo 1.jpg от 2026-09-14 к сообщению «Давай вот это блюдо лучше добавим». `user-photo-original.jpg` сохраняет исходный файл 576×1280. `fish-photo.png` — точный декодированный квадрат 576×576 с координатами left=0, top=318; чёрные поля и интерфейс телефона исключены. `fish-plate.png` добавляет прозрачность только снаружи контура тарелки. RGB непрозрачной области совпадает с исходным файлом.

Название для подписи — «Рыба с овощами». Вид рыбы, автор, место съёмки и точный состав не указаны пользователем. Подробности координат и SHA исходника сохранены в `provenance.json` и проверке итогового эскиза.
