# Рабочий стол: описание и фотографии ингредиентов

Активный результат — компонент MenuWorktable: живые текст и шесть фотографий поверх чистых страниц, исходная еда в глубокой кремовой тарелке.

- `background.png`: выбранная чистая подложка1419×1108, встроенный ImageGen. В ней нет сгенерированной еды или текста.
- `background-provenance.md`: полные исходный и корректирующий промпты, происхождение, координаты.
- `food-only.png`: настоящая еда, выделенная по цвету и контуру из присланного фото. RGB сохранён.
- `scene.png`: подложка с готовым фотослоем в тарелке; страницы намеренно чистые для HTML.
- `verification.json`: проверка76132 исходных непрозрачных пикселей и38941 пикселя итогового фотослоя,0 отличий RGB.
- `puree-sauce-study.webp`: неактивная проба фрагментов пюре/соуса, не подключена к сайту.

Скрипты: `scripts/prepare-fish-notebook.mjs`, `scripts/prepare-fish-notebook-ingredients.mjs`. Оригиналы фотографий и лицензии — `design/references/fish-notebook-ingredients-2026-09-14/SOURCES.md`. Снимки настоящего интерфейса, включая текст и mobile, — `artifacts/menu-worktable-ingredients-2026-09-14/`. Полный отчёт — `docs/MENU_WORKTABLE_INGREDIENTS_2026-09-14.md`.
