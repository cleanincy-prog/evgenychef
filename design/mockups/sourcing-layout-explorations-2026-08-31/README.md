# Sourcing layout explorations — 2026-08-31

These ten selection mockups respond to the user’s direct report that the current ingredient-sourcing field is unreadable and strangely arranged, followed by a request for five additional unconventional directions. They are not production assets and do not replace the current interface until the user selects a direction.

All concepts retain the same three stories, exact visitor-facing statements, place labels and six documentary subjects shown in the supplied screenshot. ImageGen reconstructed the photographs for layout visualization, so implementation must use the repository’s real local source files rather than pixels from these mockups.

1. `01-editorial-triptych.png` — three unequal vertical editorial chapters.
2. `02-horizontal-source-route.png` — one left-to-right typographic route above a continuous evidence strip.
3. `03-cinematic-chapter-bands.png` — three alternating horizontal story bands.
4. `04-editorial-index-evidence.png` — a readable text index paired with a compact evidence field.
5. `05-documentary-feature-spreads.png` — three magazine-like feature spreads with dominant and supporting images.
6. `06-diagonal-staircase-route.png` — a descending diagonal route with statements occupying its landings.
7. `07-central-typographic-spine.png` — three statements in one central forest spine with paired evidence alternating on both sides.
8. `08-oversized-place-framework.png` — enormous outline place names used as the compositional framework.
   - `08b-selected-category-framework-full-frame.png` — user-selected correction with `МЯСО`, `РЫБА`, `ОВОЩИ` and the complete uncropped Larnaca seller frame.
9. `09-serpentine-documentary-route.png` — an S-shaped sequence whose statements occupy the interior bends.
10. `10-offset-editorial-apertures.png` — six offset image apertures cut through one continuous paper-and-forest field.

Shared constraints: warm paper/forest project palette; square edges; large Cyrillic statements; close text-to-image association; no generic cards, rounding, shadows, gradients, glass, glow, icons, badges, buttons or invented copy.
