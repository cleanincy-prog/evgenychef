# Final ImageGen Prompt Set

Mode: built-in ImageGen. Use case: `ui-mockup`. All outputs are tall desktop full-page comparison boards for the same current one-page Russian private-chef site.

Shared content sequence: restrained header; personal-chef hero; MasterChef biography; product sourcing; three event formats; Instagram inquiry; sparse footer.

Shared prominent copy: `Евгений Грыбенюк — ваш личный Мастер-Шеф на Кипре`; `От MasterChef к вашему столу.`; `Я не работаю по меню, я его создаю.`; `Вечера бывают разные`; `Расскажите мне, чего хочется.`

Shared constraints: preserve the chef identity from supplied local references; use the current service meaning; avoid lorem ipsum, fake supplier claims, invented credentials and luxury claims; no generic SaaS sequence, stock testimonials, pricing, FAQ, rounded card system, bento preset, glass, glow, digital gradient, stock avatar, decorative 3D object, unrelated logo or watermark.
