# Site Style Unification Study — 2026-08-31

Status: comparison-only study. The live route, its components and its running development process are intentionally unchanged.

## Audit summary

The active page currently contains five coherent but visibly different visual languages:

1. **Documentary mosaic** — the hero uses a dense irregular field of real chef imagery, a complete warm-paper veil, one sharp identity portrait and display copy over the field.
2. **Editorial biography** — the chef story uses quiet paper, large Oranienbaum headlines, fine rules, asymmetric photo/text relationships and long-form reading rhythm.
3. **Cyprus tapestry** — the home chapter adds locally authored botanical/Lefkara ornament as a structural image field rather than a small decorative icon.
4. **Product route** — sourcing uses oversized outline nouns, paired documentary evidence and clipped rectangular statements in paper and forest.
5. **Watercolour invitation** — inquiry uses a complete brush-and-wash Cyprus villa illustration, a very sparse reading field and one dark-green action.

These are real project directions rather than external templates. The shared content for every comparison is the same: header, personal-chef hero, MasterChef biography, product sourcing, three event formats, Instagram inquiry and footer.

## Elements that currently look inconsistent

| Existing element | Why it reads as a separate style | Comparison treatment |
|---|---|---|
| Hero mosaic | Image-dense, layered and photographic while the rest of the page is mostly open paper | Extend irregular documentary apertures, veils and overlaid identity moments through every major block |
| Chef biography | Calm magazine spread with linear reading rhythm and almost no filled panels | Re-author every block as an asymmetric editorial spread with one dominant image and hairline rules |
| Cyprus ornament | Hand-painted local pattern is much more illustrative and ornamental than adjacent documentary blocks | Let the tapestry become the recurring structural grid, section divider and restrained identity field |
| Product route | Oversized outline words and clipped forest statements create a graphic exhibition language | Use large outline taxonomy, evidence pairs and clipped statements consistently for all sections |
| Inquiry close | Watercolour, abundant reserve and quiet invitation behave like a different tempo | Carry full-frame brush illustrations, soft-edged media and generous authored reserve through the whole page |

## Retained content and assets

- Exact current service, biography, sourcing, format and inquiry meaning.
- Real local chef and event photographs; no generated substitute person.
- Current warm paper, ink, copper and forest color family.
- Current Oranienbaum/Onest typographic roles as the baseline.
- Square-edged, non-SaaS composition; no stock cards, bento preset, gradients, glass or generic marketing sections.

## Implementation plan

1. Use the approved current section itself as the primary reference for its direction.
2. Apply that direction to the same six-part page sequence without copying an outside brand or inventing a new service.
3. Use the real local chef photographs as documentary inputs and preserve identity.
4. Save all generated boards only in this comparison directory; do not import them into `app/`, `public/`, routes or styles.
5. Review the five boards for accidental SaaS/card patterns, unrelated decoration, invented text, identity drift and loss of the current color family.
6. Do not select or implement a winner until the user chooses a direction.

## Open decisions

- Which direction becomes the approved system.
- Whether the chosen direction should be applied literally or combined with one secondary motif.
- Final desktop and mobile implementation values; these stay undecided until a direction is selected.

## User clarification applied

The comparison is not a recoloring exercise. Each board changes the structural system:

- mosaic: dense photographic partition and evidence-led rhythm;
- editorial: open long-form spreads and dominant text/image relationships;
- tapestry: painted local pattern as a recurring structural field;
- exhibition route: dark wayfinding canvas, monumental outline type and route geometry;
- watercolour: continuous illustrated hospitality story with organic brush transitions.

## Result and anti-template audit

All five boards were generated in built-in ImageGen mode from project-local references and saved only in this directory. No route, component, stylesheet, public asset, package or running process was changed.

The overview confirms that the directions differ in grid, typography, media treatment, graphic language, density and page tempo rather than only hue. None uses a centered two-button hero, stock testimonial strip, pricing, FAQ, generic SaaS dashboard, glass, glow or repeated rounded card system. Board 04 intentionally uses three route stations, but they are unequal exhibition fields tied together by one authored wayfinding line rather than a reusable card grid.

Limitations: these are raster decision mockups. Small generated body copy is not authoritative, some supporting scenes are illustrative composites, and face fidelity is approximate even though the real chef photographs were supplied as identity references. Production must use the exact local media and current verified copy. Responsive behavior at 1440, 1280, 1024, 768, 430, 390 and 375 px remains intentionally undecided until the user selects a direction; the live site itself retains its existing verified behavior.
