# Рабочий стол с исходной фотографией утки

[Готовый эскиз 1536×1024](menu-worktable-real-duck-v1.png).

Запрос: «Нет, утку которая была на сайте, её делай, не рисованную». Цветная тарелка — прежнее фото сайта `public/media/web/duck-plate-960.webp`; побайтовая копия сохранена как `original-site-duck.webp`. Атрибуция находится в `public/media/menu/CREDITS.md`; фото используется как пример подачи, авторство шефу не приписывается.

ImageGen подготовил только подложку: убрал прежнюю нарисованную цветную тарелку и согласовал маленький карандашный рисунок с оригиналом. Затем `compose.mjs` вставил фотографию отдельным слоем: пропорциональное уменьшение до 650×601, координаты 944/398, обрезка краем холста. Контактная тень находится под фото. Цвет, еда, соусы и гарнир не генерировались и не ретушировались.

Для повторной сборки из корня проекта: `node design/mockups/menu-worktable-2026-09-13/real-duck/compose.mjs`. Полный запрос и происхождение подложки — [provenance.json](provenance.json). Проверка — [verification.json](verification.json): хеш исходника и копии совпадает; все 280415 непрозрачных пикселей уменьшенной фотографии совпадают с финальным PNG, отличий 0.

Визуально проверены фотографическая подача, нижний набросок, меню и расположение предметов. Это отдельный эскиз; активные файлы сайта не изменялись, публикация не выполнялась. Предыдущие варианты сохранены.
