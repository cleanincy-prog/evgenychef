# Premium graphic directions — comparison set

Status: **direction 04 is selected for the independent `codex/mise-en-place-blueprint` review
version; directions 01, 02, 03 and 05 remain comparison-only; none is the production site**. These
five bitmap mockups answer the user's request to compare richer graphic treatments for the long cream
story and sourcing fields. The Hero and the complete villa close remain the existing visual anchors
and are not redesign targets.

All five concepts use the user's current phone captures as layout/content references and share the
active project constraints: warm cream/ivory surfaces, near-black ink, restrained antique gold,
Cormorant Garamond-style display typography, Montserrat-style reading typography, square media edges,
real-chef identity, meaningful graphics, and no cards, radii, shadows, glass, gradients, generic UI or
green page surfaces.

The generated Russian copy and some photographic details are illustrative only. If a direction is
selected, implementation must use the exact current site copy and approved local photographs; it must
not treat an image-generated market, dish, supplier or venue as documentary evidence.

## 01 — Culinary atlas

File: `01-culinary-atlas.png`

Prompt direction: a single fine copper route line connects the workday and the three sourcing stages;
restrained contour lines, coordinate ticks and ingredient engravings turn the page into a bespoke
field map without becoming repeated wallpaper.

## 02 — Watercolour atelier

File: `02-watercolour-atelier.png`

Prompt direction: one complete ink-and-watercolour gesture anchors each chapter—chef at work, plated
dish, ingredient study and olive-table close—while formerly empty reserve becomes authored atmosphere
rather than decorative pattern.

## 03 — Cinematic editorial

File: `03-cinematic-editorial.png`

Prompt direction: precise documentary bleeds, contact-sheet registration marks, clipped serif
fragments and one restrained charcoal interlude create a luxury magazine sequence while photos and
copy remain tightly paired.

## 04 — Mise en place blueprint

File: `04-mise-en-place-blueprint.png`

Prompt direction: preparation arcs, a measured plating plan, knife/cut diagrams and ingredient anatomy
occupy the cream reserve as meaningful chef-work notation; the visual language is intended to be
implementable with restrained SVG and CSS.

Selected implementation scope: transfer only the preparation-route, plating-plan, culinary-contour
and ordered-sourcing principles into accessible responsive HTML/CSS/SVG. Keep the current exact copy,
approved local media, cream palette, Cormorant Garamond/Montserrat typography, square geometry, Hero
and complete villa close. Generated dishes, photographs, times, measurements, handwritten notes and
other factual-looking details in the bitmap are not approved content.

## 05 — Tactile letterpress

File: `05-tactile-letterpress.png`

Prompt direction: subtle cotton-paper grain, blind-debossed apron/tool/ingredient reliefs, fine
engravings and small copper registration marks create material richness without floating cards or
shiny faux-luxury effects.
