# Prompt set

Use case: `infographic-diagram`  
Asset type: unapproved mobile website layout underlay for a discussion mockup.

Shared composition contract:

- square warm-ivory technical-paper canvas;
- two completely blank central live-content apertures;
- one connected drawing system across the top, slim side continuations, the narrow middle gap and a
  larger bottom resolution;
- fine graphite/charcoal construction, antique-brass arrows, restrained sage and dusty terracotta;
- medium-scale focal objects rather than scattered miniature icons;
- no readable words, numbers, logos, watermark, border frame, embedded photo, UI chrome, rounded card,
  shadow or gradient;
- no mark enters either live-content aperture;
- no tall object tower, miniature bottom sticker, repeated people rows, mirrored stations, dense foliage
  or richly shaded banquet spread.

Format prompts:

1. **Private dinner:** ingredients and preparation tools on the upper/side route; one sauce or plating
   gesture in the centre gap; seven distinct courses and one intimate round-table endpoint below.
2. **Private event:** griddle and mise en place above; one serving hand or tray route in the centre gap;
   four bite assemblies, two trays, a few standing guests and one replenishment return below.
3. **Masterclass:** knives, herbs and one demonstration gesture above; correction/feedback through the
   centre gap; two different practice stations and three plated outcomes on a restrained bench below.

Each generation used its approved `*concept-v3.png` desktop drawing as the sole style/topology reference.

## Second-round edit

The three `v6` perimeter sheets were used as edit targets. The built-in edit pass removed approximately
35–40% of secondary foliage, repeated objects, loose ingredient scatter and people; enlarged the intended
photo apertures; and preserved only the format-specific top route, one middle connector and a simplified
bottom outcome. Dinner retains seven courses, event retains four bite types/two trays/four guest figures,
and masterclass retains one demonstration/two practice gestures/three outcomes.
