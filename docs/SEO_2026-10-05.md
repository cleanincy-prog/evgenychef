До изменения главная уже возвращала 200, разрешала индексацию и имела canonical; robots.txt и sitemap.xml работали. www перенаправлялся на основной домен, неизвестный путь возвращал 404. В HTML отсутствовали структурированные данные. `noindex` в локальном public — предусмотренная защита предпросмотра.

Главный экран, шесть глав, три формата и контакт — существующий утверждённый интерфейс. SEO не добавляет визуальные блоки, FAQ, страницы городов, карточки, отзывы или UI-библиотеки. H1 с именем и расположенное рядом описание роли/Кипра сохраняются. Все услуги доступны в исходном HTML без выполнения JavaScript.

В этот выпуск также входит уже готовая локальная доработка от 5 октября: маленькое видео занимает собственную последнюю ячейку коллажа Hero, имеет общий blur/затемнение и не перекрывает фотографии. Источник — текущие `public/assets/hero-collage.css`, комментарии `src/hero-collage.mjs` и проверенные превью `output/hero-video-grid-2026-10-05/` в рабочей папке Biotrofi. Это перенос существующего решения, а не новый дизайн.

## Реализация

- Title: «Частный шеф-повар на Кипре — Евгений Гребеник».
- Description описывает ужин в 7 подач, мероприятия, мастер-классы и персональное меню.
- Один модуль `src/seo.mjs` формирует metadata, абсолютные canonical/OG/Twitter URL, сведения об изображении и правила индексации.
- В production HTML включён JSON-LD: WebSite, WebPage, Person, ImageObject и три Service. Описания берутся из видимого контента; provider связан с шефом, область обслуживания — Кипр. `sameAs` содержит существующий Instagram. Это семантическая разметка, а не обещание rich results.
- В production включён выданный Google HTML-тег подтверждения. Это публичный код владения, не пароль. Сохранять его при будущих публикациях.
- Sitemap содержит только реальную canonical-страницу. Фрагменты не выдаются за отдельные страницы; lastmod не подменяется временем сборки.
- Production разрешает большие превью изображений. Локальный сервер отдаёт HTTP `X-Robots-Tag: noindex, nofollow`, public и preview-сборка остаются noindex.
- Сборка генерирует итоговый HTML из шаблона, без замены отдельных строк noindex/canonical. Проверка `check:seo` предотвращает потерю индексации, canonical или подтверждения владения.

## Проверки перед выпуском

```sh
npm run build:preview
node scripts/check-seo.mjs --preview
npm run build
npm run check
npm run check:seo
```

Проверены HTTP, медиа и диапазоны видео, неизменность body между режимами, отсутствие горизонтального переполнения и Hero на ширинах 1440, 1280, 1024, 768, 430, 390, 375 px. Мобильное меню открывается, ссылка обновляет URL контакта; полная визуальная повторная проверка неизменённого контакта не завершена из-за таймаута браузера. Новых библиотек, шаблонных блоков и декоративных решений не добавлено. Квитанция публикации и результаты Search Console сохраняются рядом с изолированным checkout в `output/seo-2026-10-05/` рабочей папки.

## Google

Создаётся URL-prefix ресурс `https://evgenychef.com/` в уже авторизованной Google-сессии владельца. После публикации: подтвердить HTML-тег, отправить `https://evgenychef.com/sitemap.xml`, проверить URL через live test и запросить индексирование. Факт добавления ресурса, успешное подтверждение, получение sitemap и принятие запроса индексирования — отдельные состояния. Их итог фиксируется в квитанции, а не предполагается по наличию тега.

Обход и включение в индекс контролирует Google; даже принятый запрос не гарантирует появление или позиции. Google Business Profile и карты — отдельная регистрация бизнеса, для которой нужны реальные контактные данные и подтверждение; она не имитируется JSON-LD.
