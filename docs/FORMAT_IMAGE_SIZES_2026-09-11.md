# Фотографии форматов одного размера без обрезки — 2026-09-11

## Предварительный аудит и план

Пользователь попросил сделать изображения «Частный ужин», «Приватные мероприятия», «Мастер-классы» одного размера, затем уточнил «но не обрезаны». Проверены app/page.tsx, CSS и дизайн-документация, все три исходника просмотрены. Фотография ужина вертикальная (1152×1572), две другие горизонтальные (2278×1510, 1144×770). Сейчас desktop использует общий блок с contain, но с выравниванием вправо; на телефоне ужин имеет отдельную высоту 255 px, остальные — 3:2.

План до правки: общие области 3:2, полученные из существующей мобильной композиции. До 900 px сохраняется нынешняя сетка; выше 620 px ширина области min(100%,270px), высота задаётся 3:2 (максимум прежние 180 px); ниже 620 px — вся ширина контента. Изображения contain/center, исходные пропорции и весь кадр сохраняются. Разница пропорций компенсируется фоном --paper #F4EFE5. Удалить индивидуальные размеры и позиционирование. Другие компоненты сохраняются; новых нет. Новых шаблонных элементов не требуется.

Референсы — прямой запрос, текущая сетка «План вечера», мобильное 3:2 и бумажная палитра. Решений без референса и новых UI-библиотек нет. Важная геометрическая оговорка: одинаковы области изображений; видимые прямоугольники фото разных пропорций при полном сохранении кадра не могут одновременно совпасть по ширине и высоте. Это объяснено пользователю до реализации.
