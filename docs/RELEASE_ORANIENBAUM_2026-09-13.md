# Публикация Oranienbaum и фотографической сцены — 2026-09-13

Прямое указание пользователя «Внеси на сервер» разрешает выпуск готовой локальной версии на существующий публичный evgenychef.com. Оно заменяет прежнее ограничение localhost-only для шрифтовой системы и завершённой сцены меню. Сохраняются проект Sites appgprj_6a981b9ab8708191b17ebf66cc5f818f, аудитория public, домен и GitHub cleanincy-prog/evgenychef/main. Предыдущая опубликованная версия остаётся в истории.

## Состав

- Oranienbaum400 для логотипа, заголовков и названий частей блюда; Ysabeau Office400/500/600/400italic для текста и интерфейса; PT Mono400 для чисел. Двенадцать локальных WOFF2, swap, два кириллических preload, без синтеза. [Аудит и точные параметры](ORANIENBAUM_2026-09-13.md).
- Законченная сцена «Продумываю меню»: реальные фото с прозрачным фоном, стена и угол стола в палитре сайта, адаптивные подписи, локальная страница авторства. [Источники и проверка](MENU_EXPLODED_PHOTOS_2026-09-13.md).
- Сохранены тексты, правильное имя Евгений Гребеник / Evgen Grebenik, Hero, стикеры форматов, маршрут40%/+55px, видео, Instagram, контакты и индексируемые метаданные домена. Самостоятельные неутверждённые макеты и их документация остаются локальными.

## Проверки выпуска

Перед публикацией выполняется финальная сборка Sites/Vinext с проверенными исходниками и актуальными сведениями об авторстве фотографий. Код интерфейса и изображения после визуальных проверок не менялись. TypeScript и пять существующих HTTP-тестов прошли. Проверка пробелов проходит для исходников и отчётов; официальные PT-MONO-OFL.txt и YSABEAU-OFFICE-OFL.txt сохраняются побайтно, включая исходные пробелы в конце строк, согласно хешам manifest. Desktop/tablet/mobile1440/1280/1024/768/430/390/375px просмотрены; реальные Rendered Fonts подтверждены, горизонтального переполнения и ошибок загрузки нет. Проверены200% текста, фокус, hover, интерактивные цели, задержка шрифтов, отсутствие JavaScript, ошибка и повтор видео, reduced motion. Подробные результаты сохранены в artifacts/oranienbaum-2026-09-13 и artifacts/menu-scallops-2026-09-13.

Публикация сохраняет точный исходный commit и собранный Worker со статическими ресурсами. После завершения проверяются HTML и CSS домена, локальные шрифты, фото, robots/sitemap и отсутствие localhost-noindex. Результат публикации сохраняется локально в artifacts/oranienbaum-2026-09-13/deployment.json.

Ограничение: проверки Chrome/macOS, без физического Safari/iOS. Нового редизайна или UI-библиотек в выпуске нет; итоговый антишаблонный аудит пройден.
