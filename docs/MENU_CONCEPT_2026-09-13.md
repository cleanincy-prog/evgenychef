## Исправление: исходная фотография утки с сайта

Последнее прямое «Нет, утку которая была на сайте, её делай, не рисованную» отклоняет генеративную утку. До работы установлено по `MENU_BOOK_PENCIL_COLOR_2026-09-13.md`, `CREAM_DUCK_PLATE_2026-09-11.md`, `site-images.ts` и `menu/CREDITS.md`: настоящая фотография, использовавшаяся на сайте, — `public/media/web/duck-plate-960.webp`, версия исходного фотографического выреза `personal-menu-duck-plate-cream-v2.webp`. Атлас `duck-photo-atlas-1536.webp` является нарисованной подачей и для цветной тарелки больше не используется.

План: убрать генеративную тарелку из подложки рабочего стола, согласовать нижний карандашный набросок с исходной подачей. Затем вставить сам фотографический файл отдельным слоем с пропорциональным уменьшением и естественной локальной тенью. Цветная утка не проходит через генерацию или ретушь; генерируется только подложка и рисунок на бумаге. Исходный фотослой остаётся неизменным файлом, метод сборки и проверка сохраняются. Это выполняет прямое требование использовать фотографию, а не перерисовывать еду. Состав реального гарнира не переименовывается в сельдерей/морковь по старому генеративному атласу. Пример меню, выбранная композиция и остальные предметы сохраняются. Активный сайт не затрагивается.

Готов [исправленный эскиз с исходной фотографией](../design/mockups/menu-worktable-2026-09-13/real-duck/menu-worktable-real-duck-v1.png), 1536×1024. ## Коррекция после отклонения первого эскиза

Следующий запрос «Можешь дать идею лучше» смещает обсуждение от повторения прежней сцены к новому концепту. Предложение: рабочий стол шефа — раскрытый блокнот с кратким меню и набросками подач, несколько цветных продуктов и одна готовая тарелка, частично заходящая на страницу. Центр композиции — разработка меню; асимметрия и воздух берутся из действующего сайта, блокнот и сочетание графита с цветной едой — из исходного референса. Это предложение, а не выбранная пользователем версия. Предыдущая корректирующая генерация сцены с людьми не становится финальным решением автоматически. Интеграция по-прежнему отложена.

Первый эскиз отклонён прямым «Выглядит ужасно». Он не является утверждённым источником для интерфейса. Повторно сверены исходный пользовательский рисунок, портрет Евгения и состав генерации. В первом варианте центральная фигура чрезмерно крупная, плотная штриховка приближает людей к портретному рисунку, а отдельно созданные тарелки и подписи воспринимаются как каталог. Это оценка исполнителя по сравнению с референсом; конкретная причина недовольства пользователя уточняется.

План нового эскиза до работы: создать одну цельную иллюстрацию в пропорциях цветной области референса. Более мелкий шеф за раскрытым блокнотом, лёгкие незалитые линии и минимум штриховки; беседа слева, компактные ингредиенты справа, четыре небольшие эллиптические тарелки внизу под единым ракурсом. Цвет только у еды. Подачи связаны со сценой тонкими линиями. Без каталожных подписей, сетки и отдельных панелей. Действующие фон и характер сайта сохраняются. Новый общий стиль не вводится; источник композиции — предоставленное фото, лицо — прежний портрет. Первая версия остаётся для истории. Активный сайт по-прежнему не изменяется.

**Последнее уточнение:** «Сначала эскиз потом всё остальное». Эта итерация ограничена отдельным визуальным эскизом; активный сайт, его исходники, GitHub и публикация не изменяются. План интеграции ниже отложен до выбора пользователем эскиза.

## Результат

Выполнен только отдельный эскиз по последнему уточнению. [Большой экран](../design/mockups/menu-concept-2026-09-13/verification/menu-1440.png), [телефон](../design/mockups/menu-concept-2026-09-13/verification/menu-390.png), [HTML-макет](../design/mockups/menu-concept-2026-09-13/index.html).

Созданы HTML-макет, два исходных PNG, provenance.json с полными запросами ImageGen, семь снимков разных ширин и снимок при 200% текста. Исходные изображения не редактировались; в макете применяется CSS darken/brightness для согласования бумаги, квадранты атласа размещены через CSS. Изменены только AGENTS.md и три проектных дизайн-документа для фиксации нового запроса и ограничения «сначала эскиз». `git diff --exit-code -- app public worker vite.config.ts package.json tests` подтвердил отсутствие изменений действующего сайта. Коммит, push и публикация не выполнялись.

Антишаблонный аудит: карточек, книжной рамки, повторяющихся оболочек, градиентов и анимации в эскизе нет. Четыре блюда в ряд происходят из прямого референса. Личность шефа и шрифты — из действующего проекта. Выбор подписей и размеров — адаптация примера, не новая утверждённая услуга. UI-библиотеки не добавлялись.

Отдельный макет просмотрен на ширинах 1440, 1280, 1024, 768, 430, 390 и 375 px. Все изображения загружаются, текст не обрезан, горизонтального переполнения нет. При 200% текста на 375 px блюда переходят в одну колонку, подписи сохраняются. Ошибок JavaScript нет. Проверены пропорции, цвет, читаемость, переносы и отсутствие прямоугольных подложек. [Измерения](../design/mockups/menu-concept-2026-09-13/verification/report.json).

Ограничения: это первый визуальный эскиз. Блюда и их изображения иллюстративные. Интеграция в существующий процесс, адаптация внешних стрелок, состояния загрузки/повтора и сборка сайта отложены до выбора пользователем — это следующий этап, не незавершённая часть текущего эскиза.
