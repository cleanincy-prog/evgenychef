# Присланное блюдо в блокноте — 2026-09-14

Прямое «Давай вот это блюдо лучше добавим» с фотографией выбирает новый цветной фотослой для рабочего стола. Предыдущая утка и найденные варианты BOKA/Beckett’s больше не являются выбранным блюдом. Фото показывает рыбу с обжаренной кожей, зелёным пюре, горошком, овощами и мидиями; точный вид рыбы и рецепт по изображению не устанавливаются. Подпись — «Рыба с овощами».

## Аудит и план до изменения интерфейса

Проверены MenuWorktable, его CSS и подпись, page.tsx, источник изображения, действующие проверки HTTP, ранее одобренный `menu-worktable-v1.png`, подложка без тарелки и присланный кадр 576×1280. Сайт уже показывает блокнот в этапе 02. Сетка, стрелки, шрифты Oranienbaum / Ysabeau Office / PT Mono, остальные разделы и состояния загрузки сохраняются.

1. Шаблонных элементов для замены нет. Проблема относится к выбранной фотографии и согласованности блюда с наброском, а не к структуре сайта.
2. Композиционный источник — одобренный рабочий стол; содержательный источник — новая фотография пользователя. Сохранить блокнот, предметы, ракурс и масштаб исходной композиции.
3. Скопировать пользовательский файл в `design/references/menu-fish-2026-09-14/`. Убрать чёрные поля и интерфейс телефона. Реальный фотослой не генерировать, не ретушировать и не менять его цвет. Для прозрачного окружения использовать контурную маску тарелки, затем пропорциональный размер и отдельную контактную тень. Сверить непрозрачные пиксели с исходным фото после масштабирования.
4. В существующей подложке ImageGen меняет только строку меню на «Рыба с овощами» и нижний карандашный набросок по новому фото. Цветная тарелка накладывается из пользовательского снимка отдельно. Полный промпт и результат сохраняются для воспроизводимости.
5. Экспортировать три WebP lossless, переключить текущий компонент на них, обновить alt и читаемую подпись меню. Ссылка источника ведёт к присланной фотографии без полей телефона; авторство Евгения не заявляется. Старые медиа сохранить для отката.
6. Новые компоненты и библиотеки не нужны. Обновить существующие проверки под выбранное фото; проверить декодирование, полный кадр, доступность ресурсов, SSR, локальный noindex и сборку. Проверить готовую композицию визуально.
