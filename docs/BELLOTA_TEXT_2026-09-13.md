# Bellota Text — выбранный третий вариант, 2026-09-13

## Аудит и план до изменения интерфейса

Прямое «Третий вариант» выбирает Bellota Text из пяти показанных макетов. Источник для внедрения — выбранный desktop1440 и его mobile390, сохранённые в design/references/approved-bellota-text-{desktop,mobile}-2026-09-13.png. Это замена гарнитуры на всём сайте, как в выбранном образце и предыдущей пробе Shantell Sans.

Проверены AGENTS.md, app/page.tsx, layout.tsx, globals.css, действующая дизайн-система и карта референсов, прежний отчёт Shantell, сценарии visual/loading QA и имеющиеся локальные шрифты. Bellota Text из официального Google Fonts CSS имеет настоящие кириллический и латинский WOFF2 normal400, использованные в макете. Лицензия SIL OFL хранится рядом с файлами.

1. Необоснованных шаблонных элементов в затрагиваемой типографике не найдено. Существующие компоненты, тексты, фотографии, карандашные иллюстрации, бумажные стикеры и все действия остаются.
2. Подключить те же два файла Bellota Text400, что в выбранном макете, вместо активного Shantell Sans. Сохранить встроенную в CSS загрузку inline/block и отключённое искусственное начертание.
3. У Bellota Text нет веса500. В образце при единственном подключённом400 и font-synthesis:none все роли фактически использовали400. Явно сопоставить прежние500/600 с400 для точного соответствия выбранному образцу.
4. Сохранить существующие размеры, межстрочные интервалы, цвета, контейнеры, сетки, брейкпоинты, рамки, тени, выноски и состояния. Размер Hero46px desktop и28.08px при390px. Менять геометрию только при подтверждённом дефекте размещения текста; записать решение до исправления.
5. Новых компонентов и UI-библиотек не требуется. Shantell и Caveat остаются в репозитории для отката.
6. Проверить1440/1280/1024/768/430/390/375px: пять строк Hero, границы текста, читаемость, подписи тарелки, стикеры, изображения, навигацию, hover/focus, цели действий, видео/reduced motion/retry. Форм и состояний пустых данных нет. Переиспользовать существующие проверки HTTP, загрузки шрифта и сборки.
7. По сохранённому прямому разрешению обновить main GitHub и существующий публичный Sites-проект, сохраняя домен, аудиторию и историю. Локальный preview остаётся127.0.0.1:3004 сnoindex.

Новых композиционных решений без референса нет. Источник гарнитуры: https://fonts.google.com/specimen/Bellota+Text . Макет пользователя определяет роль и размер, текущая одобренная система определяет остальные разделы.

## Результат и проверки

Bellota Text normal400 подключён ко всем типографическим ролям. Настоящие шрифты совпадают побайтно с выбранным макетом; основной текст17–18px и подписи16px сохраняют прежние размеры. Изменения геометрии не потребовались. Два WOFF2 встроены в CSS, без отдельных сетевых запросов шрифта.

Успешно прошли сборка Sites/Vinext, пять существующих HTTP-проверок, visual QA на1440/1280/1024/768/430/390/375px, клавиатурныйfocus и цели44px, hover кнопки на всех ширинах, reduced motion, ручное/автоматическое воспроизведение видео, ошибка и «Повторить». Все фотографии загружены, пять строкHero помещаются, горизонтального переполнения нет. Восемь сценариев холодной загрузки/reload/замедленногоCSS/безJavaScript подтвердили готовность Bellota к первому содержательному показу и стабильную геометрию после него.

Дополнительная проверка реальных текстовых границ не выявила обрезания. ДляHero граница — бумажная панельhero-copy: утверждённый отступ золотой строки намеренно выходит за собственную ширинуh1, оставаясь внутри панели. Первоначальное сравнение сh1 было излишне строгим; после проверки метрик уточнён только QA, а не интерфейс. Header/footer при200% размера текста на375/390px помещаются.

Визуально просмотрены все семь ширин и снимки отдельных секций. Независимый просмотр1440/1280/1024/375px подтвердил читаемость, отсутствие пересечений текста с маршрутом/тарелкой, сохранение композиции выбранного макета. На1024px сохранены прежние полезные запасы подписи «Текстуры» и этапа03.
