# Видео приготовления в ленте — 14 октября 2026

## Запрос и аудит до реализации

Пользователь заменяет тарелки во вступлении «Какой будет ваш вечер?» тремя квадратными видео без рамок: крем из кондитерского мешка, переворот стейка, украшение канапе. Движение остаётся линейным, как у существующих тарелок. Основа — опубликованная Sites 138, source `d86cd8718eb1f1b229b2877459c4e8e0926bb102`.

Проверены `src/dish-marquee.mjs`, CSS/JS ленты, шаблон и перевод главной, `bao-motion.css`, манифест медиа и текущие документы. Сайт статический, восемь страниц RU/EN, Cormorant Garamond / DM Sans, коричневый фон. Сохраняется недавний порядок: заголовок и описание → медиа → текстовая лента, компактная высота desktop и отдельная мобильная компоновка.

Шаблонных элементов, которые требуется заменять, не обнаружено. Нынешняя лента соответствует прямому запросу, но её изображения больше не соответствуют выбранному содержанию. Повторяются только технические группы бесшовной ленты; карточки, подписи и дополнительный декор не нужны.

## План до правок интерфейса

1. Сохранить композицию, типографику, фон, интервалы, линейный темп 56 s / 40 s и существующую кнопку паузы.
2. Заменить изображения в существующем модуле на три настоящих ролика с двумя одинаковыми группами. Новых визуальных компонентов и UI-библиотек не требуется.
3. Обрезать исходные кадры вокруг действия, подготовить MP4 H.264 720×720 / 25 fps без аудио и WebP-постеры. У видео нет рамки, скругления, тени и панели проигрывателя.
4. Загружать ролики при появлении раздела; останавливать их вместе с лентой по паузе, вне экрана и при скрытии вкладки. Reduced motion и отсутствие JS оставляют постеры. Отказ autoplay не должен давать пустой квадрат.
5. Проверить сборку, все восемь SEO-страниц, семь обязательных ширин, RU/EN, загрузку, повтор, паузу, focus, отсутствие overflow и отказ загрузки. Выпустить в существующие Sites, GitHub main и домен.

## Проверка и выпуск

Сборка production, `npm run check`, `npm run check:seo` и `git diff --check` прошли. Восемь страниц RU/EN, canonical/hreflang, sitemap и Search Console сохранены. 224 медиа сверены с манифестом. Три MP4 занимают вместе 3,408,952 байта, H.264 720×720 / 25 fps, аудиопотоков нет; длительности 6.52 / 8 / 8.32 s. Постер стейка выбран после переворота, на 6.4 s подготовленного фрагмента.

Браузерная проверка в установленном Google Chrome:

- RU: 1440×900, 1280×720, 1024×768, 768×1024, 430×932, 390×844, 375×667, дополнительно 320×568 и 844×390. EN: 1440×900 и 375×667. Все раскладки прошли: изображения тарелок отсутствуют, шесть video в двух одинаковых группах, квадратная геометрия, нулевые рамки/скругления/тени, нет пересечений и горизонтального overflow.
- Desktop 1440 и mobile 390: реальное декодирование и продвижение времени каждого из трёх роликов, muted/inline/loop, линейное движение, непрерывный стык групп (<1 px), клавиатурная пауза обеих лент и всех видео, возобновление, остановка вне экрана. Цель управления 44×44 px и видимый focus.
- Reduced motion при загрузке: нет запросов новых MP4, статичные постеры. Динамическая смена настройки останавливает видео и CSS-анимацию. Скрытие вкладки проверено через симуляцию `visibilitychange`.
- No-JS и принудительная ошибка MP4 оставляют постеры; симулированный запрет autoplay снимается нажатием существующей кнопки. Ошибок JS в обычных проверках нет.
- Скриншоты и машинные результаты: `output/video-marquee-2026-10-14/qa/`. Сам скрипт проверки остаётся вне production-источника.

Созданы `public/media/chef/cooking-reel/` (три MP4 и три WebP) и этот отчёт. Изменены `src/dish-marquee.mjs`, `src/media-manifest.json`, `public/assets/dish-marquee.css`, `public/assets/dish-marquee.js`, сгенерированные RU/EN главные и три документа проектирования. Новых npm/UI-библиотек нет.

Финальный аудит: композиция соответствует прямому запросу, дополнительные карточки, подписи и декоративные эффекты не добавлены; новые решения без источника отсутствуют. Видео являются реальными стоковыми материалами. Физические iPhone/Android и энергосберегающий режим Safari не проверялись; для ограничения autoplay предусмотрены постер и запуск кнопкой.
