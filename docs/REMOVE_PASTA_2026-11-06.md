# Удаление машинки с пастой — 6 ноября 2026

Запрос пользователя: удалить машинку с пастой с evgenychef.com. Основа — текущая опубликованная версия Sites 141, commit `fb2459b5ce8e1116b662824e9258f8f6d88c39e4`; отдельная рабочая копия получена из исходного репозитория Sites.

## Аудит и источник решения

На опубликованных RU/EN главных страницах `scripts/render.mjs` подключает отдельные `story-pasta.js` и `story-pasta.css`. Модуль создаёт фиксированный декоративный Canvas, загружает `pasta-machine.jpg` и анимирует ручку и ленту теста при прокрутке. Контент глав, размеры, снимки, тарелка, её четыре пояснения и навигация реализованы отдельно. До загрузки машинки уже работает штатный маршрут этапов из `story-timeline.css` и `process.js`.

Референс — существующий опубликованный интерфейс и прямой запрос пользователя на удаление. Новый стиль не выбирается. Шаблонные элементы в пределах правки не добавляются; убирается только запрошенный декоративный объект. Новые компоненты и UI-библиотеки не требуются.

## План до изменения интерфейса

1. Удалить оба подключения машинки из общего шаблона RU/EN.
2. Удалить ставшие ненужными JS, CSS и изображение машинки; убрать только его запись из медиа-манифеста.
3. Сохранить существующий маршрут чтения, размеры ленты, фон, типографику, контент, видео и четыре пояснения к блюду. Локальный эксперимент с новым видео утки в эту публикацию не переносить.
4. Собрать все восемь страниц, выполнить `npm run check` и `npm run check:seo`, проверить отсутствие загрузчика машинки и целостность неизменённых страниц.
5. Проверить RU/EN и геометрию ленты на ширинах 1440, 1280, 1024, 768, 430, 390 и 375 px, затем опубликовать в том же публичном Sites-проекте и на прежнем домене.
