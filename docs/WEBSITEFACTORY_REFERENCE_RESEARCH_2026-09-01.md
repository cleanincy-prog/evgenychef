# WebsiteFactory reference research — approved application set

Status: **approved by the user for application to this copied Site on 2026-09-01**.

The research was assembled from the WebsiteFactory 2.0 workshop catalog. Its catalog contains
1,869 exact elements and 5,607 seed links. This project uses the following 28 exact elements and
keeps the required three discovery links for each element. Discovery links are not copied as
layouts; the implementation uses only the concrete principles documented below.

## Application boundary

- Preserve all approved copy, forty hero sources, portrait, event photographs, award proof, story film,
  sourcing evidence, villa illustration and section order.
- Replace `Instagram` as the primary visual label with the outcome `обсудить вечер`; the destination
  remains the verified Instagram link and is announced in the accessible name.
- Essential hero copy and photographs are visible on the first frame.
- Noninteractive images do not react to hover or press.
- One major pattern band marks each chapter change. Interior rules remain only where they frame
  evidence or distinguish event stages.
- Functional labels are at least 11 px. Interactive targets remain at least 44 px and become
  48–52 px or larger on compact screens.
- Only feedback/navigation motion remains: color/underline state and a one-pixel active press.
  Reduced motion removes smooth scrolling and movement. Documentary video remains poster-first,
  muted, viewport-controlled and paused when reduced motion is requested.
- Exact final spacing, crops and breakpoints remain the existing approved values unless visual QA
  proves a collision. No form or contact channel is invented.
