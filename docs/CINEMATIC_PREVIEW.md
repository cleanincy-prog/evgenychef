## Анимация непрерывной ленты

Каждый заголовок, абзац и подпись появляется отдельно при прокрутке: когда 12% элемента входит в область на 48px выше нижнего края окна. Проявление длится 850ms; у заголовков и абзацев есть мягкий сдвиг на 22px. Четыре подписи к тарелке проявляются на месте вместе со своими линиями, сохраняя точное соединение с ингредиентами. Анимация срабатывает один раз при первом появлении каждого элемента. Наблюдение начинается после загрузки страницы, шрифтов и восстановления начального якоря, чтобы анимация не проигрывалась до чтения. Размытая фотоподложка движется в пределах 14px вслед за прокруткой; основной кадр сохраняет масштаб и композицию. Общая линия слева заполняется оливковым цветом по мере чтения. Колесо, касания и прокрутка остаются нативными.

Анимация добавляется через IntersectionObserver и Web Animations API. До инициализации и без JavaScript текст виден; ожидающие прокрутки элементы скрываются только работающим скриптом. При печати весь текст виден, фокус клавиатуры немедленно раскрывает активный элемент. При `prefers-reduced-motion` отключаются появления и движение фона; активные анимации отменяются при изменении настройки, фокусе на элементах ленты и скрытии страницы. Обновление прогресса выполняется через requestAnimationFrame по событиям прокрутки, без постоянного цикла в простое.
