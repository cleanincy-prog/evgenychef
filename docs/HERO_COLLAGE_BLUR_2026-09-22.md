# Небольшое усиление размытия коллажа — 2026-09-22

## Аудит и план до изменения

Пользователь просит немного больше blur на существующем коллаже Hero. Сейчас у готового коллажа blur(2px); во время трёхсекундного вступления filter:none защищает плавность. Источник — прямой запрос и существующий утверждённый Hero, без нового оформления. Портрет и текст находятся вне фильтруемого коллажа.

Изменить только статический blur с 2 до 3 px. Это умеренное увеличение на 1 px, рабочая интерпретация «немного». Сохранить фотографии, их сетку, портрет, текст, цвет, шрифты и все остальные разделы. Анимация и её контроллер сохраняются целиком, включая отсутствие фильтра при движении. Шаблонных элементов нет; компонентов и библиотек не добавляется. Проверить семь обязательных ширин, итоговые фильтры/геометрию и production build; затем публикация в существующие GitHub/main и evgenychef.com по текущему разрешению.

## Результат и проверки

В globals.css изменено одно значение фильтра: 2 → 3 px. В существующей проверке Hero обновлено ожидаемое значение. Контроллер анимации, изображения, тексты и остальные исходники страницы не менялись.

Визуально проверены 1440, 1280, 1024, 768, 430, 390 и 375 px. На всех размерах filter коллажа — blur(3px), карточки/портрета — none; горизонтального переполнения нет. Сохранение геометрии, текста и исходных фотографий зафиксировано в verification.json. Мобильное воспроизведение: во время running — filter:none, после завершения — blur(3px). Production build успешен. Новые тесты и библиотеки не добавлены.

Созданы этот аудит и снимки/verification.json; изменены app/globals.css, ожидание в scripts/qa-hero-intro.mjs и записи AGENTS / DESIGN_REFERENCE_MAP / DESIGN_SYSTEM / IMPLEMENTATION_PLAN. Шаблонных элементов не найдено и не добавлено, нового оформления нет. Источник — прямой запрос и прежний Hero; величина +1 px — умеренная интерпретация пожелания. Проверка выполнена в Chrome с мобильными размерами, не на физическом iPhone.
