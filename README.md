# Евгений Гребеник — одностраничный сайт

Визуальная основа Biotrofi, содержание и выбранные фото/видео из проекта «Шеф4». Главная страница на русском языке: три формата, биография и шесть этапов в кинематографичной ленте: от знакомства и выбора продуктов до подготовки и ужина. Оригинальные фото, тарелка Atlas с пояснениями и настоящее видео. Контакт — Instagram.

## Запуск

Требуется Node.js 20+. Установка npm-зависимостей не нужна.

```sh
npm start
```

Предпросмотр: http://127.0.0.1:5173. Отдельное кинематографичное превью и публичная ссылка описаны в [docs/CINEMATIC_PREVIEW.md](docs/CINEMATIC_PREVIEW.md).

```sh
npm run render     # Пересобрать HTML после изменения содержимого
npm run check      # Локальные ссылки, медиа, SHA-256, целостность страницы
npm run build      # Создать production dist для evgenychef.com
npm run preview    # Открыть dist на порту 5173 (остановить основной сервер)
node scripts/check.mjs --http  # Проверить работающий сервер и byte ranges видео
```

## Где редактировать

- `src/content.mjs` — тексты, форматы, этапы и контакт.
- `src/process.mjs`, `public/assets/process.css`, `process.js` и `public/assets/story-timeline.css` — шесть кинематографичных глав с фотографиями, ингредиентами, описанием вкуса, управляемым видео и прямым контактом в Instagram.
- `public/media/chef/letter/` — фотографии этапов и их адаптивные версии; вечер использует `evening-chef-wine.webp`, подготовка — `preparation.mp4`. Происхождение материалов и устройство блока описаны в `docs/PROCESS_LETTER.md`.
- `src/hero-collage.mjs` — исходная последовательность анимированной заставки «Шеф4»: 62 фотографии и одно маленькое видео `hero-cooking.mp4` вместо 50-го фото, в нижней части Hero под большим портретом. Ролик 4,6 с из Azuravideo начинается с мидий на огне; монтаж без первой сцены хранится в `output/azura-chef-cut/`.
- `scripts/render.mjs` — структура главной страницы; генерирует `public/index.html`.
- `public/assets/local.css` — композиция и адаптивность.
- `public/assets/bao-site.js`, `bao-motion.css` — прокрутка с фиксацией секций, горизонтальные переходы форматов, меню и окна с механиками BAO London. Длинные секции сохраняют свободную прокрутку внутри блока. Предыдущий `site.js` больше не подключается.
- `public/assets/hero-collage.js`, `hero-collage.css` — коллаж первого экрана и мобильная раскладка. Фотографии собираются за две секунды, затем за 650 мс появляются текст и затемнение. Ожидание загрузки ограничено; для уменьшения движения предусмотрена статическая версия. Маленькое видео запускается после заставки, играет без звука по кругу, останавливается вне экрана и имеет кнопку паузы; при уменьшенном движении остаётся постер с ручным запуском.
- `public/assets/hero-snapshot.js` — подготовка размытого фона коллажа для плавного появления и прокрутки; большой портрет остаётся чётким поверх него.
- `public/assets/reference.css`, `public/assets/fonts/` — сохранённые стили и шрифты визуального референса.
- `public/media/chef/` — выбранные фотографии, постеры и видео.
- `src/media-manifest.json` — происхождение, назначение и хеш каждого медиафайла.
- `src/service-renders.mjs` — широкие, почти квадратные и вертикальные рендеры фонов трёх форматов.
- `output/service-renders/` — исходные PNG рендеров, промпты и параметры генерации.
- `docs/CONTENT_ADAPTATION.md` — что куда перенесено и почему.
- `reference/biotrofi-placeholder/` — архив исходной версии с заглушками, вне сборки.

Сайт статический. Кнопка контакта открывает Instagram `@evg.chef`; сервер не принимает заявки. Подстраниц и зависимости от сайта Biotrofi нет. Локальная версия имеет `noindex,nofollow`; production-сборка автоматически включает индексацию и canonical для https://evgenychef.com/.

Оригинальная папка «Шеф4» не редактировалась. По уточнению пользователя фоновые фото трёх форматов расширены через imagegen: дорисовано окружение для полноэкранных блоков. На широких, высоких и мобильных экранах используются разные композиции. Оригинальные фотографии сохранены в окнах «Подробнее». Обработка и контрольные суммы указаны в `src/media-manifest.json`. Тексты биографии — редакция от 22 сентября 2026, основного содержания — от 20 сентября 2026.


## Публикация на evgenychef.com

Основной домен: https://evgenychef.com/. GitHub: https://github.com/cleanincy-prog/evgenychef, ветка `main`. Хостинг — существующий публичный Sites-проект из `.openai/hosting.json`. GitHub сам не запускает деплой: точный commit также сохраняется в source repository Sites, затем публикуется архив `dist` этого commit. Публикация выполняется workflow из Sites Hosting. История предыдущей реализации сохранена. Подробности выпуска и отката: `docs/DEPLOYMENT_2026-10-03.md`.
